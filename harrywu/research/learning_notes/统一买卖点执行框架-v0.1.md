# 统一买卖点执行框架 v0.1

## 1. 文档定位

本框架用于统一不同交易策略最终落地的具体买卖点。

上层策略负责回答：

- 为什么交易；
- 交易哪个板块和个股；
- 做多还是退出；
- 在什么价格区域寻找机会；
- 原始逻辑何时失效。

本执行框架负责回答：

- 具体在哪个周期等待；
- 哪个价格结构出现后允许买入；
- 哪个价格结构破坏后执行卖出；
- 哪些情况下不得继续等待形态。

当前版本只确定总体结构，不固定趋势线算法、成交量阈值、等待根数及各策略的具体参数。

---

## 2. 核心原则

### 2.1 双突破和双跌破是统一执行层

除明确列出的例外策略外，各类策略产生交易意图后，原则上不直接成交，而是交给统一执行层寻找具体买卖点：

```text
上层策略产生交易意图
→ 板块资金与个股量能过滤
→ 双突破确认
→ 执行买入
→ 持仓管理
→ 双跌破或硬风险条件
→ 执行卖出
```

### 2.2 资金与成交量前置

普通买入必须有资金和成交量支持。价格形态不能取代资金条件。

总体顺序为：

```text
市场环境
→ 板块资金流与龙头表现
→ 个股量价结构
→ 策略条件
→ 具体价格触发
```

基本要求：

- 板块没有资金支持时，普通形态买点降低优先级或取消；
- 个股没有成交量支持时，普通突破不视为有效买入触发；
- 长期底部完成吸筹、成交量收缩后再放量突破，为最高优先级结构；
- 突破放量、回踩缩量、再次上涨重新放量，是优先量价结构；
- 资金流和成交量的具体口径在后续数据研究中确定。

### 2.3 形态名称不构成限制

允许的底部结构包括但不限于：

- W底；
- 圆弧底；
- 头肩底；
- 箱体；
- 三角形；
- 菱形；
- 其他能够形成明确上沿、颈线或平台压力的底部整理结构。

程序化时优先识别“底部结构及其突破边界”，不强制先给形态命名。形态名称主要用于人工解释和复盘。

### 2.4 形态质量、趋势惯性与盈亏比

形态用于筛选和排序时，采用以下经验原则：

1. 形态构筑周期越长，突破后的潜在行情通常越大；
2. 形态越规整、边界越清楚、有效触点越充分，优先级越高；
3. 牛市中，小底部也可能推动大涨，而大顶部可能只产生小跌；
4. 熊市中，小顶部也可能引发大跌，而大底部可能只产生小涨；
5. 任何形态都必须同时衡量成功概率、止损距离、前方沽压和潜在盈亏比。

第3、4点反映的是长期趋势惯性，不得机械解释为“小形态永远优于大形态”。其具体含义为：

- 顺长期趋势的延续结构可以产生超出形态规模的行情；
- 逆长期趋势的第一次反转结构容易失败或只形成有限反弹；
- 形态周期和完整度决定潜在空间，市场环境决定行情兑现程度。

讲师提出的“长期牛市中第一次反转尝试约有80%概率被止损”“长期熊市中第一次向上双突破约有70%概率回调”，当前只作为经验假设，不直接作为程序概率或仓位比例。必须按市场环境、方向和尝试次数分别回测。

## 3. 普通买入执行框架

### 3.1 前置资格

一笔普通买入进入执行层前，至少应提供：

- 上层策略给出的方向和候选区域；
- 当前属于牛市、熊市还是震荡环境；
- 板块资金状态；
- 板块龙头或核心个股表现；
- 个股成交量状态；
- 形态构筑周期和形态质量；
- 当前是同一轮反转结构的第几次有效尝试；
- 前方沽压距离和预期盈亏比；
- 原策略硬止损或逻辑失效位置；
- 用于执行的K线周期。

### 3.2 第一突破：趋势突破

价格突破局部下降趋势线后：

- 只进入“买入观察”状态；
- 不因单独突破趋势线立即买入；
- 继续等待底部形态、平台或颈线形成并突破；
- 趋势线的自动画法后续按一般技术分析规则细化。

### 3.3 第二突破：结构突破

价格进一步突破第二层关键价格边界后，构成第二突破。该边界可以来自：

- W底、圆弧底、头肩底、箱体、三角形等底部形态的上沿或颈线；
- 2B等反转结构的确认价位；
- 前期成交量累积区或Volume Profile筹码密集区；
- 关键支撑压力互换区域；
- 其他经过多次交易、具有明确量能或价格记忆的结构边界。

普通买入触发原则为：

```text
下降趋势线已经突破
+ 第二层关键结构边界已经突破
+ 板块资金条件有效
+ 个股成交量支持
= 双突破买入触发
```

两次突破允许：

- 同一根K线发生；
- 相邻K线发生；
- 先突破趋势线，经过一段整理后再突破形态。

当前版本不固定等待K线根数。第一突破后的观察状态，在以下任一情况出现时结束：

- 第二突破成立，执行买入；
- 底部结构被向下破坏；
- 原策略交易条件失效；
- 板块资金或个股量能条件失效；
- 等待时间过长，原趋势线和形态已经不再具有同一技术含义。

### 3.4 买入后的初始保护

成交后必须立即存在硬风险边界。该边界由上层策略、账户风险预算和执行结构共同确定。

优先参考的结构止损锚点包括：

- 前一底部形态的关键低点或右肩低点；
- 箱体、平台或其他入场结构的失效位置；
- 前期主要成交量累积区或筹码密集区下方；
- 上层策略已经定义的更严格失效位置。

双突破负责改善具体进场点，但不能取消：

- 单笔最大风险；
- 原策略逻辑失效位置；
- 极端行情保护；
- 无法正常形成价格结构时的退出方案。

### 3.5 分代尝试与递进仓位

在长期趋势第一次尝试反转时，第一次有效双突破仍然必须参与，但原则上只使用试探仓，以避免直接反转时完全踏空，同时控制原趋势惯性导致的失败成本。

```text
第一次有效双突破
→ 小仓试错
→ 成功：继续持有，等待后续加仓点
→ 失败：立即止损，仓位归零

重新形成完整且独立的价格结构
→ 第二次有效双突破
→ 重新检查资金、量能和市场环境
→ 条件仍成立时提高仓位档位

第三次重新形成有效双突破
→ 条件继续增强时允许进一步提高仓位档位
→ 不得突破单笔和整个策略的风险上限
```

该规则属于证据逐步增加后的仓位管理，不是亏损加仓：

- 每次失败必须先执行止损；
- 第二次、第三次必须来自重新构建的独立结构；
- 不得把同一根K线反复穿越边界计算成多次尝试；
- 每次重试都重新检查板块资金、龙头表现和个股量能；
- 资金或量能已经失效时，不得仅因尝试次数增加而提高仓位；
- 顺势双突破与逆势反转尝试必须分别统计，不共用尝试成功率。

具体仓位比例暂不固定。最终仓位应同时考虑：

- 市场环境和顺逆势关系；
- 形态周期与完整度；
- 当前尝试次数；
- 止损距离；
- 前方沽压距离；
- 预期盈亏比；
- 单笔及组合风险预算。

### 3.6 成功入场后的加仓

第一次试探仓直接成功时，不因初始仓位较小而追价补足。优先等待以下结构加仓：

- 突破后的支撑压力互换和回抽确认；
- 新形成的形态再次突破；
- 趋势延续过程中新的双突破；
- 量价继续配合、板块资金和龙头表现仍然有效的确认点。

每一次加仓都视为新的风险决策，并同步上移或重新计算整体保护位置。

## 4. 普通卖出执行框架

### 4.1 双跌破定义

双跌破与双突破方向相反：

```text
上升趋势线跌破
→ 第一跌破，进入退出观察

上涨平台、局部支撑或形态下沿跌破
→ 第二跌破，执行卖出
```

第一跌破和第二跌破可以发生在同一阶段，也可以先跌破趋势线、反弹或整理形成平台后，再跌破平台支撑。

### 4.2 止盈模式

当上层策略的止盈条件满足后，不一定立即全部卖出，可以转入结构化跟踪止盈状态：

- 默认观察15分钟或30分钟结构；
- 到达前方主要沽压位或原策略目标位时，可以先兑现第一部分仓位；
- 第一跌破后进入退出观察；
- 上升趋势线跌破时，可以兑现第二部分仓位；
- 第二跌破成立后，退出剩余跟踪仓位；
- 允许后续按策略设置分批退出或利润保护线；
- 硬风险条件始终具有更高优先级。

该模式的目标是让盈利头寸继续运行，减少因固定百分比或单根K线波动造成的过早卖出。

分批比例暂不固定。课程示例包含“趋势线跌破先出一部分、双跌破再全部退出”以及“沽压位、趋势线跌破、形态跌破分三批退出”两种表达，后续通过回测决定各策略采用两段式还是三段式退出。

### 4.3 风险预警模式

当价格开始转弱、但尚未触及硬止损或原策略失效条件时，可以进入风险预警状态：

```text
价格转弱或首次跌破趋势线
→ 暂不必立即卖出
→ 等待反弹或平台形成
→ 反弹失败后再次跌破平台
→ 执行卖出
```

这种处理只适用于风险仍处于预算范围内的情况。

### 4.4 硬止损模式

以下情况不得为了等待双跌破而继续持有：

- 已触及预先定义的硬止损；
- 原策略逻辑已经明确失效；
- 出现连续单边下跌，无法形成反弹平台；
- 出现跳空、流动性恶化或其他极端风险；
- 继续等待会使单笔损失超过账户风险预算。

硬止损一旦触发，直接执行，不等待成交量确认、反弹或第二跌破。

因此，本框架不允许用“双跌破”放宽硬止损。可以在硬止损之前设置风险预警区，并在该区域内等待反弹后的双跌破。

### 4.5 成交量在卖出侧的作用

- 放量跌破提高卖出信号的紧迫性和可信度；
- 缩量跌破可以结合收盘确认、反抽和平台破坏判断；
- 成交量可以增强或减弱普通卖出信号，但不能否决硬止损。

## 5. 例外执行模式

以下策略暂不强制等待双突破买入：

### 5.1 涨停排队

涨停排队缺乏正常连续的价格发现过程，无法要求先形成完整趋势线和平台突破。按涨停策略自身的排队、撤单、封单和风险规则执行。

### 5.2 弱转强追随

弱转强买点主要依赖当时的：

- 板块实时资金流；
- 龙头强度；
- 集合竞价和开盘表现；
- 个股量价转强；
- 市场情绪与晋级关系。

该类策略如果等待完整双突破，可能失去有效成交窗口，因此按弱转强策略自身的即时触发规则执行。

例外策略只豁免普通双突破入场流程，不豁免成交量、资金、仓位和硬止损管理。

## 6. 状态机

统一执行层暂定使用以下状态：

```text
EXCLUDED          不具备资金、量能或策略资格
QUALIFIED         具备交易资格，等待价格结构
ENTRY_ARMED       已突破下降趋势线，等待第二突破
ENTERED           双突破成立，已经买入
HOLDING           正常持仓
PROFIT_TRAILING   已达到止盈条件，使用15/30分钟双跌破跟踪
RISK_WATCH        尚未触及硬止损，但价格结构已经转弱
EXIT_ARMED        已发生第一跌破，等待第二跌破
STOPPED_REBUILD   试探仓止损，等待新结构重新形成
EXITED            已执行卖出
HARD_STOP         硬风险条件触发，立即退出
```

主要流转关系：

```text
QUALIFIED
→ ENTRY_ARMED
→ ENTERED
→ HOLDING
→ PROFIT_TRAILING 或 RISK_WATCH
→ EXIT_ARMED
→ EXITED

第一次试探失败
→ HARD_STOP
→ EXITED
→ STOPPED_REBUILD
→ 重新通过资金、量能和结构检查
→ ENTRY_ARMED

任何持仓状态
→ HARD_STOP
→ EXITED
```

## 7. 上层策略接入要求

以后每个策略接入统一执行层时，应尽量提供以下字段：

| 字段 | 含义 |
|---|---|
| 策略名称 | 产生交易意图的策略 |
| 标的与方向 | 个股及买入/退出方向 |
| 市场环境 | 牛市、熊市或震荡，以及当前顺逆势关系 |
| 候选区域 | 允许寻找买点的价格区域 |
| 主周期 | 上层策略判断所用周期 |
| 执行周期 | 等待双突破的周期 |
| 止盈跟踪周期 | 默认考虑15分钟或30分钟 |
| 板块资金状态 | 是否满足资金前置条件 |
| 龙头状态 | 龙头是否支持该笔交易 |
| 个股量能状态 | 是否存在有效量能支持 |
| 形态周期 | 当前结构构筑时间及所属周期 |
| 形态质量 | 结构边界、触点和完整度的评价 |
| 结构代次 | 同一轮趋势反转中第几套独立结构 |
| 尝试次数 | 当前是第几次有效双突破尝试 |
| 风险档位 | 本次允许使用的试探或递进仓位等级 |
| 前方沽压 | 最近主要压力或成交密集区的距离 |
| 预期盈亏比 | 目标空间与结构止损距离之比 |
| 硬止损 | 不允许继续等待形态的位置或条件 |
| 止盈启动条件 | 何时从持仓切换为跟踪止盈 |
| 有效期限 | 该交易意图何时失效 |
| 例外类型 | 普通、涨停排队或弱转强 |

## 8. 后续细化项目

以下项目保留到后续版本确定：

1. 枢轴高低点和趋势线自动画法；
2. 趋势线有效触点数量和容差；
3. 平台、颈线和底部区域的识别算法；
4. 突破采用盘中越线还是收盘确认；
5. 第一突破后最长等待时间；
6. 板块资金流数据源与统一口径；
7. 个股放量、缩量和长期底部量能的阈值；
8. 不同主周期对应的买入执行周期；
9. 15分钟和30分钟止盈跟踪的切换条件；
10. 双跌破中的平台生成和反弹失败定义；
11. 分批买入、加仓、减仓和分批止盈规则；
12. 涨跌停、跳空和无法成交情况下的处理；
13. 第一次、第二次和第三次尝试的风险档位与仓位比例；
14. 形态周期、完整度和触点质量的评分方法；
15. 沽压距离与盈亏比对仓位的修正方法；
16. 同一轮结构的尝试计数与重置条件；
17. 做空时的镜像执行规则。

## 9. 回测验证结构

每个策略至少比较以下四个版本：

1. 原始策略：按原买卖点直接执行；
2. 入场优化：买入增加双突破，退出保持原规则；
3. 退出优化：买入保持原规则，退出增加双跌破；
4. 完整执行层：买入双突破，止盈双跌破，硬止损保持独立。

重点比较：

- 胜率；
- 盈亏比；
- 单笔期望；
- 最大回撤；
- 买入延迟和错失率；
- 止盈后的利润回吐；
- 硬止损发生率；
- 资金利用率；
- 不同市场环境和不同周期下的稳定性。
- 牛市、熊市和震荡环境中的分组结果；
- 顺势与逆势双突破的分组结果；
- 第一次、第二次和第三次尝试的独立胜率与盈亏比；
- 不同形态周期和形态质量分组的结果；
- 不同沽压距离下的收益空间和失败率；
- 两段式与三段式退出的利润回吐和最终收益。

只有经过上述对照，才能判断双突破或双跌破究竟改善了执行质量，还是仅仅延迟了交易。

## 10. 当前已确定、不得混淆的规则

1. 普通策略的具体买点优先使用双突破；
2. 趋势线突破本身只产生观察信号，不直接买入；
3. 第二次形态或平台突破才触发普通买入；
4. 普通买入不能缺少板块资金和个股量能支持；
5. 各类底部形态统一抽象为“底部结构及其突破边界”；
6. 止盈可以使用15分钟或30分钟双跌破适当放宽；
7. 风险预警后可以等待反弹及再次双跌破；
8. 硬止损不能等待双跌破，也不能等待成交量确认；
9. 单边下跌且不形成平台时，硬风险规则直接接管；
10. 涨停排队和弱转强追随暂列为普通双突破入场的例外；
11. 任何例外均不豁免资金、量能、仓位和风险控制；
12. 形态周期越长、结构越完整，原则上具有更高的候选优先级；
13. 牛熊环境决定形态兑现程度，顺势和逆势信号必须分开统计；
14. 长期趋势第一次反转双突破使用试探仓，失败后必须先止损归零；
15. 第二次、第三次重新形成独立结构时，才允许重新评估并递进仓位；
16. 递进仓位是新信号上的证据加权，不是对亏损头寸摊平；
17. 概率、沽压距离和盈亏比共同决定最终仓位；
18. 沽压位、趋势线跌破和形态跌破可以构成分批退出顺序；
19. 讲师给出的70%、80%等经验概率不直接写入程序；
20. 所有参数、概率和画线方法必须在历史数据上独立验证。
