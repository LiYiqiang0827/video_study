# 本地音视频基建：本次改进与共通化交付

日期：2026-09-30｜发行版本：local-media-platform 2.1.0｜验收：Codex

## 一、已经完成的改变

| 改进 | 原来的状态 | 现在的状态 | 对理解视频的帮助 |
| --- | --- | --- | --- |
| 原分辨率画面复核 | 主要依赖 ASR 和有界视频/OCR 抽样 | 新增 `frame_review` / `frames`，逐点精确寻址、保留原分辨率和实际解码 PTS | 白板、趋势线、细小标签可以与讲解对照 |
| 疑点补看 | 需要另外写临时取图命令 | `--times` 指定秒数或分秒；自动联系表及可搜索 HTML | 能补看短暂出现的幻灯片和现场修正 |
| 画面与语音证据绑定 | 两类结果分开阅读 | 用同源 SHA-256 验证，图旁显示附近约 25 秒的转写候选 | 降低看错图、错配前后讲解的风险 |
| 画面续跑和校验 | 通用识别已有续跑；新画面复核链路尚无独立检查 | 画面参数、源及已生成帧哈希逐项检查，冲突拒绝续跑 | 复核可继续，证据替换可发现 |
| 独立安装 | 核心藏在“推し活”目录，其他项目需加 PYTHONPATH | 中立源码 + 可安装 wheel；任何项目目录都可调用 | 新项目无需复制脚本或依赖某个业务项目路径 |
| 统一入口 | 分散的模块命令 | `python -m media_platform ingest / frames / verify / doctor` | 调用、查环境和验收方式一致 |
| 配置与依赖分离 | 设备档案靠近项目源码 | 用户级共用配置，项目独立结果；ASR/OCR/GPU 可选安装 | 不把本机硬件测量、模型和业务资料带进每个项目 |
| 旧调用兼容 | 原项目直接导入本地模块 | 兼容桥优先加载已安装共用核心，原工作流保留 | 推し活继续工作，通用修复可供其他项目共用 |
| Windows 中文输出 | 重定向时可能随系统编码变化 | 统一 CLI 以 UTF-8 输出 | 自动化调用中文、日文路径时不出现读取编码错误 |

“逐点精确寻址”仍受实际可解码帧限制；保存请求时间与实际 PTS，验收允许有限偏差，并非声称每次都正好命中任意小数秒。

## 二、原来已有、这次复用的能力

本轮没有把下面内容算作新发明：FFmpeg 媒体探测、faster-whisper 识别、RapidOCR、长音频分块及重叠边界处理、共享昂贵进程锁、CUDA 依赖加载、CPU/GPU 资源选择、源与结果哈希、识别续跑、统一证据 schema、广播和互动等上层工作流。

中文课程采用 large-v3 / CUDA / float16、五分钟分块，是本次实际运行参数选择，不是训练了新模型。`medium` 的固定模型哈希机制也来自既有平台；其他模型名称仍未新增固定版本校验。

## 三、共通化的实际部署

- 通用源码位于用户 Documents 下的 `SharedTools/media-platform`，与业务项目分开。
- 本机常用 Python 3.12 已安装 `local-media-platform 2.1.0`；运行代码由该 Python 的 site-packages 提供，不需要手工注入“推し活”路径。
- 共用配置默认在 `%LOCALAPPDATA%/media-platform`；本机既有设备档案已复制到这里。项目用 `--output` 指定自己的产物目录。
- 交付 wheel、源码 ZIP、调用指南及校验清单，其他环境安装后使用同一接口。不是只留下“以后做成通用”的设计。
- 共用核心只含提取、画面复核、证据和环境检查。原广播翻译、ミーグリ复盘、投资报告仍在原业务项目中，未把其人物、固定素材或模型工作流装进公共包。
- 老项目包增加通用模块加载桥；原源码保留用于旧版回退。正常新版维护只修改中立源码、重建 wheel、重新安装。
- 没有创建常驻服务，也没有修改全机 PATH 或全机 PYTHONPATH。

完整安装和调用方式见同包 `跨项目音视频识别调用指南.md`。

## 四、这次怎样实现“转录之后继续理解”

云聪五段视频总长约 2 小时 25 分钟。先处理全量音轨，再阅读完整转写，建立 147 张一分钟画面样本，针对容易错读的图形和短暂幻灯片再补 22 张，共复核 169 张画面。

输出保留了五课逐段笔记、体系的前后关系、13 类买点、相近概念的区别、讲师在现场的修正、经验陈述的证据边界，以及未提供的参数。每条关键解释都有原片时间，术语纠正放在解释层，没有反过来改写 ASR 原始候选。

因此，本次验收同时包含“工具是否正确处理媒体”和“解释是否忠于图像与讲解”。完整处理音轨不表示逐字正确；169 张画面是抽样，不表示逐帧看完。课程中的胜率、盈利自述和机构行为解释也没有被升级为统计事实。

## 六、仍保留的能力边界

- 共用核心不是全自动“理解模型”；它提供可复核材料，完整理解仍须按任务逐段判断。
- 没有新增通用说话人分离、逐句烧录字幕、连续动作识别或自动保证文字准确的功能。
- 分辨率、片长与格式不保证全部兼容；当前实际验收为本机 Windows、Python 3.12、FFmpeg 与指定课程及合成样本。
- 本次不验证交易系统盈利能力，没有形成可直接实盘的胜率、仓位或有效突破阈值。
- 安装包不含模型权重；新电脑首次使用可能需要下载安装依赖和模型。GPU 可用性应按本机环境检查。
