# 07 云聪提及记录 · 统一规格 v1

- 版本：`yc_mention.v1`　日期：2026-10-10（JST）　起草：Claude　决定人：Harry
- 作用：**云聪提及一个对象（大盘、板块、个股、自己的持仓）的唯一源格式。** 全部记录合起来叫"云聪决策日志"。
- 取代：云聪直播研究框架 v0.3 第 5 节的事件与链条格式（不再使用）。
- 关系：看图工具的还原记录（RestorationRecord v3）从本格式导出；李老师的 `analysis.json` 按第 6 节映射转入；10-08 计划里"决策日志"的字段是本格式的子集。

---

## 1. 为什么要统一

同一件事——"云聪在某时刻提到了某只票"——此前有三套描述：v0.3 的事件与链条、看图工具 Amendment 3 的还原记录语义字段、李老师 PPT 背后的 analysis.json。各自合理，但不统一就会变成三堆不能合并的数据，后面的对齐、规则归纳、一致率、机器学习都没法做。

## 2. 记录单位

**一条记录 = 一个来源里、一段连续讲述中、对一个对象的一次表态。**

- 对象是一只个股时，一只股票一条。同一段里横向比较多只股票，每只一条，用 `comparison.group_id` 串起来。
- 同一视频里稍后再回到同一只股票、且动作或判断变了，另起一条。
- 讲大盘或指数：`scope.level = market` 或 `index`，一条记录。讲板块：`sector`。
- 讲一般方法、没有具体对象：`scope.level = method`（教学内容，可选记录）。
- 会员提问：照常记录，`nature.attribution = member`；云聪明确转为自己的候选或计划时，另起一条 `self` 的记录。

文件格式：JSONL，UTF-8，每行一条。每个来源一个文件 `<source_id>.jsonl`，另有合并文件和清单。

## 3. 字段

标注：**必填**＝试点就要有；可选＝有就填；后填＝不由抽取者填，由后续步骤（串链、对齐）补。

### 3.1 标识与来源 `id`、`source`

| 字段 | 必填 | 说明 |
|---|---|---|
| `schema_version` | 必填 | 固定 `"yc_mention.v1"` |
| `mention_id` | 必填 | `<source_id>#<三位序号>`，序号按视频内出现先后 |
| `revision` | 必填 | 从 1 开始；修订时追加新行、`revision+1`，旧行不改 |
| `source.type` | 必填 | `live_stream`（直播）/ `short_video`（短视频）/ `course`（课程）/ `other` |
| `source.id` | 必填 | 直播用 YouTube 视频 ID；李老师短视频用 `lv_<文件夹时间戳>`（如 `lv_20261002_111344`）；课程用 `course_<序号>` |
| `source.title` | 必填 | 原标题 |
| `source.record_start_bj` | 可选 | 录制或开播的北京时间，ISO 格式带 `+08:00` |
| `source.media_sha256` | 可选 | 原视频哈希 |
| `source.producer` | 必填 | `rocket_asr_v1`（我们的转写）/ `li_pipeline_<版本>`（李老师流水线）/ `manual` |
| `extraction.by` | 必填 | 抽取者，写模型名和档位，或 `human` |
| `extraction.at` | 必填 | 抽取时间 |
| `extraction.method_version` | 必填 | 抽取规则版本号 |

### 3.2 时间 `time`

| 字段 | 必填 | 说明 |
|---|---|---|
| `offset_start_s`、`offset_end_s` | 必填 | 原视频秒数（静音裁剪后的时间要映射回原视频） |
| `clip_ref` | 可选 | 原声片段路径 |
| `mention_time_bj` | 必填 | 提及发生的北京时间；不能确定时为 null |
| `time_basis` | 必填 | `screen_clock`（画面上的系统时钟）/ `stream_start_plus_offset`（开播时间 + 偏移）/ `recording_meta`（录制元数据）/ `last_formed_bar`（画面上最后成形的 K 线）/ `unknown` |
| `time_confidence` | 必填 | `high` / `medium` / `low` |
| `session` | 必填 | `preopen`（<09:25）/ `auction`（09:25–09:30）/ `morning` / `lunch` / `afternoon` / `postclose`（≥15:00）/ `non_trading_day` |
| `cutoff_bj` | 必填 | 还原用的可见截止时刻。多个来源不一致时取较早者；无法确定时取能确定的最早安全时点，并在 `quality.unresolved` 写明 |

### 3.3 对象 `scope`

| 字段 | 必填 | 说明 |
|---|---|---|
| `level` | 必填 | `market` / `index` / `sector` / `stock` / `own_position` / `method` |
| `ts_code` | 个股必填 | 如 `600048.SH`；按截止时的代码 |
| `name_spoken` | 个股必填 | 他口述的名称（可能是简称或误读） |
| `name_on_screen` | 可选 | 画面上的名称 |
| `identity_basis` | 个股必填 | `transcript` / `frame` / `both` / `inferred` |
| `identity_status` | 个股必填 | `confirmed` / `ambiguous` / `unknown`。不能用后来的涨跌认股票 |
| `board` | 后填 | `main` / `chinext` / `star` / `bse`，由代码推出 |
| `sector_spoken` | 板块或个股可选 | 他口中的板块或题材名 |
| `kpl_label`、`theme_cluster_id` | 后填 | 对齐步骤补，抽取者不填 |

### 3.4 性质 `nature`

| 字段 | 必填 | 说明 |
|---|---|---|
| `mention_type` | 必填 | `new_pick`（新选或新计划）/ `follow_up`（对已提过的票再判断）/ `retrospective`（主要在讲已做过的操作）/ `live_operation`（正在做）/ `member_question`（答会员）/ `comparison`（横向比较中的一员）/ `teaching_example`（举例讲方法）/ `mixed` / `unclear` |
| `attribution` | 必填 | `self` / `member` / `demo_account` / `other` / `unclear`。他念出的会员"我买了"不记成本人操作 |
| `idea_source` | 可选 | `self` / `member_recommendation` / `news` / `unknown`（例：会员推荐、他自己买入 → `attribution=self`、`idea_source=member_recommendation`） |
| `horizon` | 必填 | `short`（约 5 个交易日以内）/ `swing`（1–4 周）/ `mid_long`（中长线）/ `unspecified`。他没说就填 `unspecified`，不推断 |

### 3.5 表态 `stance`

| 字段 | 必填 | 说明 |
|---|---|---|
| `direction` | 必填 | `bullish` / `cautious` / `bearish` / `neutral` / `n_a` |
| `label_raw` | 可选 | 来源里的态度短语原样保留（如李老师 PPT 的"结构好，看压力"） |
| `checklist_quote` | 可选 | 他明确列出的检查清单原话（如"1.基本面估值 2.位置 3.量能 量堆 4.技术图形"） |

### 3.6 理由 `reasons[]`

每项：`{"tag": 枚举, "quote": 原话}`。一条记录可有多项。

| tag | 含义 |
|---|---|
| `sector_flow` | 板块资金流、板块异动 |
| `theme` | 题材、催化的强弱与持续性 |
| `volume_ratio_rank` | 量比排名 |
| `position` | 位置、空间、压力、支撑 |
| `volume_structure` | 量价结构：放量、缩量、量堆、涨有量跌缩量 |
| `pattern` | 形态：平台、突破、回抽、趋势线、N 字、三角形 |
| `intraday` | 分时表现 |
| `fundamental` | 基本面、估值（含排雷） |
| `market_env` | 大盘、情绪环境 |
| `news` | 消息、公告 |
| `stock_character` | 股性（历史波动、大幅往返） |
| `leader_status` | 龙头、补涨、跟风地位 |
| `money_mgmt` | 资金与仓位管理 |
| `other` | 其他，quote 里写清 |

### 3.7 动作 `actions[]`

每项：

| 字段 | 说明 |
|---|---|
| `action` | `plan_buy` / `buy` / `add` / `hold` / `reduce` / `sell` / `take_profit` / `stop_loss` / `watch` / `wait_condition`（等某条件再动）/ `exclude`（排除）/ `abandon`（放弃原计划）/ `other` |
| `tense` | `past` / `present` / `plan` |
| `evidence_level` | `stated_plan`（口述计划）/ `stated_done`（口述已操作）/ `frame_order`（画面显示委托）/ `frame_fill_or_position`（画面显示成交或持仓）/ `unclear` |
| `bar_ref` | `{"trade_date": "YYYY-MM-DD"或null, "period": "daily"/"15m"/"1m"/null, "basis": "explicit"/"inferred"/"unknown", "note": 文字}`；`basis` 为 inferred 或 unknown 时 `note` 必填 |
| `price_text` | 只抄原话里的价位，不推算 |
| `size_text` | 只抄原话里的仓位或金额 |
| `stated_outcome` | 他自己说的、截止前已发生的结果（如"几分钟后涨停""已获利 30% 多"） |
| `quote` | 原话 |

### 3.8 条件 `conditions[]`

每项：

| 字段 | 说明 |
|---|---|
| `kind` | `entry`（入场）/ `confirm`（确认）/ `invalidation`（逻辑失效）/ `stop`（止损）/ `target`（目标）/ `add`（加仓）/ `reduce`（减仓）/ `reentry`（回补、再参与）/ `exit`（退出） |
| `quote` | 原话 |
| `price_text` | 原话价位 |
| `price_basis` | `screen_qfq@YYYY-MM-DD`（画面显示前复权，日期为截止前最后已收盘日）/ `raw` / `unknown` |
| `relative_to` | 原话中的参照（如"图示位置""40 元附近""回到圈的位置"） |
| `time_window_text` | 原话中的时间限定 |
| `drawn_ref` | 如果条件画在图上，指向 `frame.frame_facts` 的序号 |

### 3.9 路径预期 `expected_path`

`{"quote": 原话, "shape_tags": [...], "branches": [原话分支...]}`。shape_tags 可选：`n_shape`（N 字）、`pullback_then_up`（先回杀再上）、`direct_up`、`choppy`（跌跌撞撞）、`range`、`breakout`、`retest`（回抽）、`deep_drop_then_buy`（等深跌）。

**回顾性内容不进 conditions 和 expected_path**，只进 `actions`（`tense = past`）。

### 3.10 比较组 `comparison`

`{"group_id": 字符串, "peers": [ts_code...], "rank": 整数或null, "selected": true/false, "elimination_reason": {"tag": 同 3.6, "quote": 原话}}`。rank 只在他说出或明确可排时填。

### 3.11 大盘与板块观点 `market_view`（level 为 market、index、sector 时）

| 字段 | 说明 |
|---|---|
| `index_structure` | `{"direction": "up"/"down"/"range"/"unclear", "quote": 原话}` |
| `short_term_sentiment` | `{"tone": "good"/"poor"/"rotating"/"unclear", "quote": 原话}`——用作大盘天气的外部对照，与指数结构分开记 |
| `sector_views[]` | `{"sector": 名称, "direction": 同 3.5, "path_quote": 原话}` |
| `none_stated` | 他没有独立的大盘判断时为 true |

### 3.12 画面 `frame`

| 字段 | 说明 |
|---|---|
| `frame_refs[]` | `{"path": 截图路径, "offset_s": 秒, "pts": 实际帧时间}` |
| `frame_facts[]` | 与看图工具 Amendment 3 完全相同：`{"field": chart_period/chart_adjustment/chart_window/price_label/drawn_object/indicator/order_book/auction_indicative/quote_panel/news_panel/other, "value_text", "frame_ref", "region", "read_by": human/ai_visual/ocr, "verified": bool}`；只描述，不解读意图 |
| `frame_window` | 与 Amendment 3 相同（截图上 K 线区的可见范围估计），可选 |

### 3.13 链条 `chain`（后填）

`{"chain_id": "<ts_code>#<首条 mention_id>", "prev_mention_id": ..., "event": "start"/"follow"/"end_explicit"/"end_invalidated"/"silent"/"window_end"}`。由串链步骤按代码和时间排序后填。"不再提及"本身是一种结局，要计入统计。

### 3.14 原话与质量 `text`、`quality`

| 字段 | 必填 | 说明 |
|---|---|---|
| `text.verbatim` | 必填 | 这段讲述的逐字转写（可删语气词，不改意思） |
| `text.segment_ids` | 必填 | 对应转写段号 |
| `text.summary` | 可选 | 一句话概括。**不作依据**，只给人浏览 |
| `quality.transcript_status` | 必填 | `asr_raw` / `name_corrected` / `audio_verified` |
| `quality.inference_notes` | 可选 | 模型推断，逐条写依据 |
| `quality.unresolved[]` | 可选 | 待核事项 |

## 4. 抽取规则

1. **三分开：** 原话（各处 `quote` 和 `text.verbatim`）、画面事实（`frame.frame_facts`）、模型推断（`quality.inference_notes`，以及 basis 为 inferred 的字段）。
2. **不补全：** 没说的留 null 或 `unspecified`；不推算价格；不用后来的走势认股票或改判断。
3. **截止优先：** `cutoff_bj` 先定；后续一切还原分析只用截止前的数据。
4. **新选与回顾分开：** 回顾只进 `actions`。
5. **保留没买的：** 排除、等待、放弃、说法变化都是记录，不能省。
6. **一只股票一条。**
7. **价位照抄：** 原话价位进 `price_text`；画面显示前复权时写 `screen_qfq@<截止前最后已收盘日>`。
8. **只追加：** 修订另写一行，`revision+1`，旧行保留。
9. **不为填满格式制造内容：** 整段没有可用 A 股内容就不出记录。

## 5. 最小可用版本（试点）

试点只要求"必填"字段，外加 `reasons`、`actions`、`conditions` 有内容时照填。`frame_facts`、`frame_window`、`chain`、`comparison.rank`、`kpl_label` 可以留到第二轮。

### 6.1 李老师 analysis.json（按 PPT 所见推断，拿到原件后核对）

| PPT 或 JSON 所见 | 本规格 |
|---|---|
| 视频标题、录制北京时间范围 | `source.title`、`source.record_start_bj` |
| 大纲·大盘整体看法 | 一条 `level=market` 记录的 `market_view`；"本片未作独立判断" → `none_stated=true` |
| 大纲·网友提问 | `mention_type=member_question` 的记录 |

| 个股表·云聪态度 | `stance.label_raw`（`direction` 另行判断） |
| 个股表·一句话概括 | `text.summary`（不作依据） |
| 分页要点"已做""历史操作""历史收益" | `actions`（`tense=past`），结果进 `stated_outcome` |
| 分页要点"目标""预期目标""目标止盈" | `conditions`（`target`） |
| 分页要点"退出""现阶段减仓" | `conditions`（`exit` 或 `reduce`） |
| 分页要点"回补""再参与条件""等待位置""第一笔""下跌分支" | `conditions`（`reentry`、`entry`、`add`） |
| 分页要点"量价""量能判断""筛选""选择逻辑""优点""龙头特征""个人选择" | `reasons`（按内容打 tag）；明确列清单时进 `checklist_quote` |
| 分页要点"路径""分支" | `expected_path` |
| 分页要点"压力""判断""谨慎""条件" | `reasons`（position 等）或 `conditions`，按内容分 |
| 分页要点"仓位前提""50 万元示例" | `actions.size_text` 或 `reasons`（`money_mgmt`） |
| 截图路径 | `frame.frame_refs` |
| 视频偏移、内嵌原讲解区间 | `time.offset_start_s`、`offset_end_s`、`clip_ref` |
| 北京时间（或"未确认"） | `time.mention_time_bj`、`time_basis`、`time_confidence` |
| 截图注释（如"原图圈注第一笔参考买点"） | `frame.frame_facts`（`drawn_object`，`read_by=ai_visual`） |
