李老师好，

你做的三份云聪视频解析（8 月 13 日、10 月 2 日）我们看了，非常有用。最难的那一段——把视频按股票切开、定到北京时间、截下带手绘的关键帧、配上原声——你已经自动化了，这正是我们前一阵因为太费时间而停下的部分。

我们接下来要做"云聪决策日志"：把他每次提到的大盘、板块和个股都记成统一格式，再和当天的大盘天气、题材阶段对齐，归纳他的选股和排除规则。PPT 适合人看，但没法跨视频查询和统计，所以想直接用你流水线背后的 `analysis.json`。

**PPT 不用改。** 只想请你做三件事。

## 一、先发我们这几样

1. 一两份 `analysis.json` 原件（就用 8/13、10/02 这几期）。
2. 生成它的提示词，或者简单说一下流水线的步骤（用什么转写、怎么切段、怎么选帧）。
3. 已经处理了多少期、时间范围；能不能批量跑全集。
4. 这些短视频的来源（是不是 YouTube 频道里直播以外的视频）。

## 二、在 JSON 里每只股票加这些字段

按重要性排序。没说的就留空，不用让模型去猜。

| # | 字段 | 填什么 | 为什么要 |
|---|---|---|---|
| 1 | 股票代码 | 如 `600048.SH` | 名称会重名、改名，代码才能接行情 |
| 2 | 提及类型 | 新选 / 回顾已做的操作 / 正在操作 / 答网友 / 横向比较 | "已获利 30%""昨天买的"是回顾，和新选混在一起会把胜率算高 |
| 3 | 动作 | 计划买 / 买 / 加 / 持有 / 减 / 卖 / 止盈 / 止损 / 观察 / 等条件 / 排除 / 放弃 | 现在的"态度"是自由文字，没法统计；"排除""等待"这类没买的记录最有价值 |
| 4 | 理由标签 + 原话 | 标签从这几类选：板块资金流、题材、量比、位置、量价、形态、分时、基本面、大盘、消息、股性、龙头地位、资金管理；每个标签附他的原话 | 归纳"为什么选这只、跳过那只" |
| 5 | 条件原话 | 入场、止损或失效、目标、加仓、回补，分开写；价位照抄原话，注明是不是前复权画面上的价 | 以后要按当时的图检验 |
| 6 | 持有周期 | 短线 / 波段 / 中长线 / 没说 | 他短线和中长线的检查清单不一样（8/13 是五项，10/02 是四项） |
| 7 | 归属 | 他本人 / 网友 / 不清楚；另记想法来源（如"会员推荐后买入"） | 网友说的不能算成云聪的操作 |
| 8 | 时间依据 | 北京时间是怎么得到的：画面时钟 / 录制开始 + 偏移 / 不确定 | 有几页写"北京时间未确认"，但截图右下角的时钟其实能读出来 |
| 9 | 这段的逐字原话 | 转写原文（可删语气词） | "一句话概括"是转述，归纳要原话 |
| 10 | 比较组 | 同一段里横向比较的几只，给同一个组号，写谁选中、谁被排除、排除理由 | 10/02 四只地产股的比较就是他的排序方法 |

视频级再加一项：**大盘看法拆成两格**——指数结构、短线情绪，各附原话；没讲就写"没讲"。我们拿它和大盘天气对照。

## 三、输出格式

- 每只股票每次提及一条记录（JSON Lines，一行一条），另有一条视频级记录放大盘看法和网友提问。
- 文件里写上版本号；以后字段有变化就升版本，旧文件保留。
