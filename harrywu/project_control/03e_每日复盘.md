# 03e 每日复盘

## 1. 目的

每天收盘后给出：市场环境（天气 + 研究闸门）、最多 3 个重点题材、最多 8 只次日观察候选及确认和失效条件；盘前补隔夜信息；午间（北京 11:00 = 东京 12:00）对照确认。服务 Harry 午休操作。

## 2. 自用版 v0.1（Claude，2026-10-08）

底稿是李老师 10-08 的复盘提示词。**李老师原版不动，他照常用；他不太喜欢天气，天气只在我们自用版里用。**

相对原版的五处改动：

| # | 改动 | 原因 |
|---|---|---|
| 1 | 程序先生成"复盘材料包"，模型只读不算；材料包没有的写"未知" | 封板率、相对封单等口径每天由模型现算会漂移，结果无法复现（9 月复盘机器人就坏在这里） |
| 2 | 第一步先照抄大盘天气，再补天气没覆盖的证据和反证，最后给研究闸门（可继续研究 / 谨慎观察 / 暂不形成候选） | 原版三个层面大半就是天气三读数 |
| 3 | 题材阶段增加"启动"，且必须引用材料包里的宽度序列 | 阶段词没有数字依据会漂 |
| 4 | 盘中确认固定为午间确认（北京 11:00）；只有尾盘能确认的条件标"午间无法确认" | Harry 只能午休操作 |
| 5 | 文末加 JSON 存档 | 盘前和午间要加载冻结名单；以后账本检验要用 |

口径：市场和题材统计用天气引擎的合格股票口径；候选另排除 ST、退市、次新（暂定上市不满 60 个交易日）和科创板（科创板计入统计，不进候选）。

暂定定义：封板率 = 涨停数 ÷（涨停数 + 炸板数）；封成比 = 收盘封单金额 ÷ 当日成交额；高标 = 昨日连板高度 ≥3。

## 3. 材料包（给执行方，最小可用版）

只拼接已有输出，不写新算法：天气日表当日整行与预报检验结论；测量引擎（`speculation_sentiment_lite/`）的日度和昨日群体输出；开盘啦当日涨停和炸板记录。五块内容：天气；市场补充（三大指数、两市成交额与 20 日均值比、个股收益中位数、涨停/炸板/封板率、14:30 后炸板名单、高标涨跌）；涨停明细；昨日群体表现；按开盘啦标签的近 20 日题材宽度序列。输出 Markdown + 同名 JSON，单日约 15KB；存档建议放 `policyStudy/policy/daily_review/`，按日期和模式命名。

## 4. 每天怎么用

1. 收盘复盘（东京 22:00 数据更新后）：校准期内先自己写一分钟判断，再看机器结果；跑天气"今天"入口和材料包脚本，交给模型，保存 JSON。
2. 盘前更新：只补隔夜新闻和公告，名单冻结。
3. 午间确认：加入上午数据，对照确认和失效条件。

材料包脚本做好之前：手动跑天气"今天"入口，把那一行和开盘啦涨停数据一起贴给模型。

**当前障碍：** 天气"今天"入口卡在交易日历（03c 第 4 节）。
