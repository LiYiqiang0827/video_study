## 4. 词汇约定

**状态词**（02 和 03x 统一使用）：

| 词 | 含义 |
|---|---|
| 进行中 | 有人正在执行 |
| 待启动 | 已决定要做，尚未开工 |
| 等待外部 | 卡在李老师、数据或其他外部条件 |
| 暂停 | 主动停下，现场保留，有恢复条件 |
| 部分交付 | 有可用成果，但验收未全部通过 |
| 已完成 | 按其用途验收通过 |
| 搁置 | 不再推进，资料保留 |
| 已取代 | 被新版本或新方向替代 |

**"完成"和"验收"是两件事。** 执行方说"完成"，只表示跑完；验收通过才写"已完成"。

**时间：** 文档日期用东京时间（JST，UTC+9）。行情、直播、盘中事件用北京时间（UTC+8），并写明时区。东京 12:00 = 北京 11:00。

**人名：** Harry = 吴俊捷 = 吴老师（李老师这样称呼他）。李老师 = Harry 的中学同学、项目协作者（GitHub 仓库 `LiYiqiang0827/TradingAgent`）。云聪 = Harry 的技术分析老师，YouTube `@yuncongtrade`。
