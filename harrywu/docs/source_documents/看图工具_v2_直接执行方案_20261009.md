## 4. 揭晓方法 fixed_horizon_v1（S2 实现）

目的：给每个提及案例一组口径固定、可以横向比较的后续路径，为以后逐步积累胜率打基础。本方法不判定成败，不计算胜率。

### 4.1 价格口径

- 揭晓中的所有价格都用还原阶段的锚点复权：价格 = 未复权价 × 当日因子 ÷ 还原锚点因子。
- 还原锚点取自冻结记录 view_identities 中任一视图的 `factor_lineage`，所有视图的锚点必须一致，不一致时报 `ANCHOR_MISMATCH`。
- 当前因子表中锚点日期的因子值必须与冻结值相等，否则报 `ANCHOR_MISMATCH`，该案例记为失败，不影响其他案例。
- 冻结记录没有视图时，取截止时最后一个已收盘日的因子，并标注 source 为 `fallback_last_closed`。
- 成交量保持真实量。

### 4.2 提及当天的处理与参考价

记提及时刻为 C，提及日为 D，k=1 的交易日称为参考交易日。

| C 所在时段（D 当天） | policy | 参考价 kind 与取值 | 参考交易日（k=1） | 第 1 日的高低点 |
|---|---|---|---|---|
| D 非交易日，或该股 D 无日线 | `non_trading_day` | next_session_open：D 之后第一根日线的开盘价 | 该日 | 全天 |
| C < 09:25 | `preopen_full_day` | next_session_open：D 的开盘价 | D | 全天 |
| 09:25 ≤ C < 09:30 | `auction_window` | auction_price：D 的开盘价 | D | 有分钟数据时取 09:31—15:00；没有时取全天，并在 note 中注明含竞价 |
| 09:30 ≤ C < 11:30，或 13:00 ≤ C < 15:00，且有分钟数据 | `split_by_minutes` | last_minute_close：bar_end ≤ C 的最后一根 1 分钟的收盘价；C 在 09:30—09:31 之间时用 auction_price | D | bar_end > C 的分钟（会多含 C 所在那一分钟中提及前的成交，在 note 中注明） |
| 11:30 ≤ C < 13:00，且有分钟数据 | `lunch_split` | lunch_close：11:30 那根的收盘价 | D | 13:01—15:00 的分钟 |
| 盘中或午休，但没有分钟数据 | `excluded_no_minutes` | next_session_open：D 之后第一根日线的开盘价，note 写 `REF_FALLBACK_NEXT_SESSION_OPEN` | D 之后第一个交易日 | 全天；D 当天不进入任何统计 |
| C ≥ 15:00 | `postclose_excluded` | next_session_open | D 之后第一个交易日 | 全天 |

- 分钟数据由 MinuteProvider 提供，见 S2 接口；揭晓阶段可以读取全部分钟。
- 参考价的 `raw_price` 记录未复权值。
- 参考价的 `at`：开盘或竞价取 `D 09:25:00+08:00`，分钟收盘取该分钟的 bar_end。

### 4.3 固定步长路径

- 记 S 为参考交易日起、不晚于 observed_through 的交易日序列（S[0] 为参考交易日）。
- 对每个 k ∈ {1, 3, 5, 10, 20}：
  - 若 S 的长度不小于 k：`trade_date = S[k-1]`；`close` 为该日复权收盘价；`close_return = close / ref − 1`。
  - `mfe = max(第1..k日的最高价) / ref − 1`，`mae = min(第1..k日的最低价) / ref − 1`。第 1 日的高低点按 4.2 节的规则取。同时记录取到极值的交易日。
  - 若 S 的长度不足 k，该 horizon 全部为 null，complete 为 false。
- 收益一律以小数存储（0.052 表示 5.2%），不做四舍五入；显示时再格式化。
- notes 中固定写一条："本快照不判定交易成败、不代表云聪的实际买卖价、不计算胜率。"

### 4.4 事件节点

- 事件节点保留，作为次要参考，全部用 4.1 节的口径：
  - `first_available`：参考交易日；
  - `mention_day_after_cutoff`：仅在 split 或 lunch 时出现，描述提及后的分钟高低点；
  - `interval_high` 与 `interval_low`：整个观察区间，第 1 日按 4.2 节取值；
  - `latest_available`：最后一个交易日。
- 每种 kind 只生成一个事件。同一天可以有多个事件。
- 事件描述用中文，同时写复权价（注明基准日与因子值）、未复权价和真实量，并注明"日线节点日期不等于极值的准确时刻；区间节点不表示实际买卖"。
