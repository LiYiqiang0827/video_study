# 冻结口径的实现决定

依据 sources 中同日第二版天气设计及执行书，SHA256记录在验收清单。执行书明确替代旧deck、C0及题材整合安排。本轮仅天气，旧成果保留。

1. 群体与F1保持一致。mid_obs用于新增大跌分母；精确整数分比较−5%，与跌停作并集。连板含所有≥2，不借用旧2–4板字段。缺成员保留原始/观察/停牌/缺失/不可观测计数。
2. 九个组成项全部正向标准化；高挨打表示更重。先平滑，再逐项固定2025线性P10/P90，再加权。大跌新先验分组累计k/n，a5。M1raw沿用F1分高度先验，Q(M1raw)与旧M1核验。
3. 局部缺项只重分该读数权重。质量降级不删日；天气只要求当前分支实际需要的读数。完整行情但无事件的0和缺输入严格区分。空群体n0不凭先验生成观测。
4. hit60、cont40/50、act35直接分类，无惯性、连续确认或收益反馈。ddens P99只附极端标签。旧score5原样参考，C0与THM不接入。
5. 预报只统计target≤origin的相邻有效市场日对。n0空，n1–9照报且标少样本。并列优先当前天气，再按sunny/cloudy/overcast/thunder/storm。历史众数同此规则；全期众数没有当前日，只按固定顺序，标事后。
6. 2026评价以目标日归属，共同有效分母；包括2025末→2026首日。9/30以后实际天气不可验证。LIVE日历止于9/30，下一日期未知，保留空值和原因。
