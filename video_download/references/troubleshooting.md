# 故障分类与验收

## 先分清失败发生在哪里

脚本仅保存固定错误标签，不保存原始异常、认证头、签名媒体 URL 或完整响应。`diagnostic_categories` 是警告与错误的并集；`final_error_categories` 接近最终错误，但仍可能含多个解释。需要更精确诊断时，在执行机器内对白名单字段做一次受限检查：请求阶段（网页、Player API、播放清单、媒体）、HTTP 状态、异常类、数字错误码、是否已认证、playability 状态、时长及格式。不能输出凭据或完整原文响应。

失败和中断也保留 `tls_retry_count`；`network_failures` 最多20条，仅含连接阶段、固定异常类、数字错误码、域名类别、网络后端和重连计数，不含请求地址。它只观察打开连接时的错误，不能据此排除响应体读取时断流。`UNEXPECTED_EOF_WHILE_READING` 与空格写法按同类瞬时TLS错误处理，重连预算不变。

浏览器可播放而脚本提示会员权限时，先区分导出文件中存在登录Cookie与服务器认可登录。前者不证明后者；若网页 `LOGGED_IN=false`、播放器 `loggedOut=true`，应按旧导出登录状态未被认可处理，不据此断言会员等级不足。只有实际认证失败后才请用户重新导出。

| 现象 | 判断与处理 |
| --- | --- |
| 文件缺失、格式错误或含别站域名 | 检查用户明确给定的单个导出文件；不打印解析器警告或 Cookie 行 |
| 明确需登录、需会员、Google 验证或 CAPTCHA | 停止该登录状态下的后续认证任务，请用户在浏览器处理；不能直接认定没购买会员 |
| `authenticated=true`、playability `OK`、会员可访问 | 已有访问证据；后续网络或格式错误不能当成要求再登录的理由 |
| TLS `UNEXPECTED_EOF` / curl 35 / SSL_ERROR_SYSCALL | 连接提前断开，不等于证书校验失败；先用无 Cookie 的公开页面检查现有网络，必要时在本下载进程选择已有代理的 HTTP 或 SOCKS 方式 |
| 证书验证失败 | 检查时间、证书和运行环境；不得关闭 TLS 验证，TLS 自动重连不处理该类失败 |
| HTTP 403 + PO Token 警告 | 警告不证明根因；先看失败客户端和请求阶段，不盲装 Token 服务或重复导出 Cookie |
| `web_creator` 直链 403 | 它的媒体请求可能需要 GVS Token；先尝试已验证的单独 `web_safari` + HLS。无需为了这条可用路径新增服务 |
| 单独 Safari 没有 HLS | 保留 `format_unavailable`；默认脚本不偷偷切到 HTTPS/360p。确需改变客户端或格式，先核对官方当前说明，显式指定 `--format-mode auto` 并重新完整验收 |
| `web_safari` Player API 因 TLS 被跳过 | 先诊断连接；`--tls-connection-retries 2` 只对每请求至多两次瞬时 TLS 重连，整个下载器实例额外重连总数至多六次，HTTP/认证/证书错误不在该重连范围 |
| 视频可解码但实际时长较短 | 不通过完整验收；比较冻结时长、网页时长和每条音视频轨，不把短文件长度重新当成正确答案 |
| 某条轨道缺时长或起点 | 保留 `stream_timing_requires_review`；不能把未知值当零或直接认定音画一致 |
| 元数据可读但无媒体 | `probe-only` 不能证明媒体下载或会员权限已完整验证 |

自动重试有次数上限，不能反复外层重跑逃避上限。连续失败后做一次针对性诊断；权限、验证和限流问题停止等待必要的用户操作。不要为了下载改变账户设置、全局代理或浏览器权限。

## 验收层级

程序默认完成：正文件大小、音视频轨存在、两秒时长误差、轨道起点/终点检查、完整文件全部音视频轨 `ffmpeg -xerror -v error` 解码、非零退出或任何错误输出即失败、SHA256。`--decode sample` 只检查两个片段，通过时为 `sample_checks_passed_full_decode_pending`，不能替代整段检查。

- 退出 0：依赖检查通过、资料探测成功，或技术验收通过。仍须检查具体 `mode` 和 `status`。
- 退出 2：时长、轨道、参考数据待核，或仅抽样解码通过。批处理不能计为完整成功。
- 退出 1：失败；`result.json` 保留固定错误类别，临时媒体不删除。
- 退出 130：用户中断；已建立目录时保留 `interrupted` 记录。

失败或中断时，保留已知媒体路径、参考时长及已算出的文件哈希，避免把未验收文件误认作完成品。命名与验收是两件事，拥有标题文件名不表示完整检查通过。

`technical_checks_passed` 不代表模型看过整段画面或听过声音，也不替代版权/访问权限。`quality_frames` 可用图像工具打开抽查。音频解码只证明轨道可解码；若需要确认非静音，可在执行机器抽样计算音量，只保留数字统计，不能把该统计说成人工听过。结果中保留 `visual_review`、`audio_human_listening` 的实际状态。

缺失独立参考时长时，说明只对网页资料验收；不能保证网页和所选媒体同时出错的情况被检出。视频截图可能显示其他浏览器、网址或软件窗口，那是录屏内容，不是当前浏览器上下文。
